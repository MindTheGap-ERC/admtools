# get quantile ADM

returns the quantile adm of a multiadm object

## Usage

``` r
quantile_adm(x, h, p)
```

## Arguments

- x:

  a multiadm object

- h:

  the heights at which to evaluate the adm

- p:

  percentile, as number between 0 and 1

## Value

an adm object
