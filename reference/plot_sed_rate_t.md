# plot sedimentation rate in time

plot sedimentation rate in time

## Usage

``` r
plot_sed_rate_t(x, mode = "rcll")
```

## Arguments

- x:

  adm object

- mode:

  string, "rcll" or "lcrl". Should the sedimentation rate be Right
  Continuous with Left Limits (rcll) or Left Continuous with Right
  Limits (lcrl)

## Value

invisible NULL
