# transform taxonomy object from strat to time domain

transform taxonomy object from strat to time domain

## Usage

``` r
# S3 method for class 'taxonomy'
strat_to_time(obj, x, ...)
```

## Arguments

- obj:

  `taxonomy` object as defined by the `FossilSim` package

- x:

  age-depth model

- ...:

  further parameters passed to *get_time*
