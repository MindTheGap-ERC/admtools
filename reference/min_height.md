# get lowest stratigraphic tie point

get lowest stratigraphic tie point

## Usage

``` r
min_height(x)
```

## Arguments

- x:

  an age-depth model (adm) or sediment accumulation curve (sac)

## Value

number, stratigraphic position of lowest tie point
