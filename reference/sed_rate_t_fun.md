# sedimentation rate function

returns a function that returns sedimentation rate

## Usage

``` r
sed_rate_t_fun(x, mode = "rcll")
```

## Arguments

- x:

  an adm object

- mode:

  string, "rcll" or "lcrl". Should the sedimentation rate be Right
  Continuous with Left Limits (rcll) or Left Continuous with Right
  Limits (lcrl)

## Value

a function
