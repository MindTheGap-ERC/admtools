# Total duration covered

Total duration covered

## Usage

``` r
get_total_duration(x, ...)
```

## Arguments

- x:

  age-depth model (adm/multiadm) or sediment accumulation curve (sac)

- ...:

  other options, currently unused

## Value

numeric, total duration covered by the age-depth models/sediment
accumulation curve

## See also

[`min_time()`](https://mindthegap-erc.github.io/admtools/reference/min_time.md)
and
[`max_time()`](https://mindthegap-erc.github.io/admtools/reference/max_time.md)
to extract the first/last tie point in time
