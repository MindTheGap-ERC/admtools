# plot multiadm object

plots the median age (red) and the 95 % envelope (blue) of a multiadm
object

## Usage

``` r
# S3 method for class 'multiadm'
plot(x, ...)
```

## Arguments

- x:

  multiadm object

- ...:

  parameters passed to `plot`

## Value

a plot of the multiadm object
