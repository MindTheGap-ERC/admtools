# set length units

set length units for sac, adm and multiadm objects

## Usage

``` r
set_L_unit(x, L_unit, ...)
```

## Arguments

- x:

  adm or multiadm object

- L_unit:

  length unit

- ...:

  further parameters

## Value

an adm or multiadm object with the L unit assigned
