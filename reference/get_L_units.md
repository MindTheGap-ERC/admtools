# extract length units

extracts the length unit from depth-depth curves (ddc objects)

## Usage

``` r
get_L_units(x, ...)
```

## Arguments

- x:

  an ddc object

- ...:

  other parameters

## Value

character - the length unit of `x`

## See also

[`get_L_unit()`](https://mindthegap-erc.github.io/admtools/reference/get_L_unit.md)
[`set_L_unit()`](https://mindthegap-erc.github.io/admtools/reference/set_L_unit.md)
to extract length units from age-depth models or sediment accumulation
curves
