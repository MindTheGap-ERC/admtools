# extract Time unit

extracts the Time unit from sac, adm or multiadm object

## Usage

``` r
get_T_unit(x, ...)
```

## Arguments

- x:

  sac, adm or multiadm object

- ...:

  other parameters

## Value

character - the time unit of `x`
