# set length units

set length units for depth-depth curves

## Usage

``` r
set_L_units(x, L_units, ...)
```

## Arguments

- x:

  depth-depth curve (ddc object)

- L_units:

  length units

- ...:

  further parameters

## Value

an ddc object with the L unit assigned
