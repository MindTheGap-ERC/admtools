# construct depth-depth curve from age-depth models

constructs a depth-depth curve from section 1 (described by `adm1`) to
section 2 (described by `adm2`)

## Usage

``` r
adm_to_ddc(adm1, adm2)
```

## Arguments

- adm1:

  age-depth model 1. An `adm` object

- adm2:

  age-depth model 2. An `adm` object
