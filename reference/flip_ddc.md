# reverse direction of depth-depth curve

reverses the direction of correlation of the depth-depth curve i.e., if
the original depth-depth curve maps section 1 to section 2 the flipped
curve maps section 2 to section 1

## Usage

``` r
flip_ddc(x, ...)
```

## Arguments

- x:

  a depth-depth curve (ddc object)

- ...:

  other parameters, currently unused
