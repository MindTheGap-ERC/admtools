# get highest stratigraphic tie point

get highest stratigraphic tie point

## Usage

``` r
max_height(x)
```

## Arguments

- x:

  age-depth model (adm) or sediment accumulation curve (sac)

## Value

number, stratigraphic position of the highest stratigraphic tie point
