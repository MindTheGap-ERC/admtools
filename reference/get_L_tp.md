# get height/length tie point

extracts the height/length time points from an age-depth model or
sediment accumulation curve

## Usage

``` r
get_L_tp(x, ...)
```

## Arguments

- x:

  age-depth model (adm/multiadm) or sediment accumulation curve (sac)

- ...:

  other options, currently not used

## Value

numeric vector of the time/length tie points

## See also

[`get_T_tp()`](https://mindthegap-erc.github.io/admtools/reference/get_T_tp.md)
to extract time tie points
