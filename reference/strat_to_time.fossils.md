# transform `fossils` object from `FossilSim` between time and strat domain

transforms `fossil` objects from stratigraphic to time domain \`

## Usage

``` r
# S3 method for class 'fossils'
strat_to_time(obj, x, ...)
```

## Arguments

- obj:

  the `fossils` object

- x:

  the age-depth model

- ...:

  further parameters passed to \_get_height\`
